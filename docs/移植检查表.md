# 移植检查表

此工程是 STM32F407ZG 的参考固件，运行入口由 [`USER/app_config.h`](../USER/app_config.h) 控制。新板首次上电保持 `APP_SAFE_IDLE=1`，每次只启用一个模块进行验证。

| 需要核对的内容 | 当前实现位置 | 原车默认值 / 说明 |
| --- | --- | --- |
| MCU、时钟、Keil 编译目标 | `USER/Template.uvprojx`、`USER/system_stm32f4xx.c` | STM32F407ZG；延时与定时器计算依赖 168 MHz 配置 |
| 连接器及 GPIO | [`引脚配置汇总.md`](../引脚配置汇总.md) | 引脚表只代表源码配置，不能代替 PCB 针序 |
| CAN 收发器和波特率 | `can_ZDT/board.c`、`USER/app_config.h` | 当前装配暂未使用 CAN 电机；旧 CAN1 接口为 PA11/PA12、500 kbit/s |
| 电机协议、地址及轮序 | `can_ZDT/Emm_V5.c`、`can_ZDT/yyb_move.c`、`USER/main.c` | 仅供以后启用旧 CAN 底盘时核对：原车四轮地址 2/1/3/4，通信模块、终端电阻和电机配置需实测 |
| 升降、夹爪脉宽、机构限位和供电 | `USER/main.c`、`Hardware/PWM.c`、`Hardware/servo.c` | 当前机构 PA3 升降、PA2 夹爪；源码中旧称云台、物块平台。测试范围已缩为 PA3 838–878 µs、PA2 648–688 µs，仍须核对方向与安全行程 |
| IMU 串口及航向符号 | `imu/imu.c`、`Hardware/pid.c` | USART2 PD5/PD6；上电自动扫描波特率 |
| 上位机协议 | `SYSTEM/Serial.c`、`USER/main.c` | USART1 PA9/PA10，9600 8N1；原比赛任务依赖固定数据包格式 |
| 屏幕、开关、灯 | `ckp/`、`lanya/`、`OLED/`、`LED/`、`Hardware/swith.c`、`USER/exti.c` | 核对是否安装以及高低电平极性 |

建议验证顺序：安全空闲构建与烧录、各电源轨、单个串口或输入、PA2/PA3 单个舵机空载，再进行机构联调。只有将来接入 CAN 电机时，才验证 CAN 内部回环、外部通信和底盘路线。改变运动代码后，先架空或脱开机构并确认方向、限位和急停手段。

原比赛任务的 `main.c` 中有测试阻断和项目专用状态机。把此仓库用作新项目时，应按新需求替换应用层任务逻辑；不要把原车路线作为通用算法直接烧录。

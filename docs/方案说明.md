# 集成板方案说明

本页把原 `gcs-gold-medal-main/PCB/方案说明（重要！先看）.docx` 中与固件和当前装配有关的内容整理到 Git 仓库，方便接收 Bundle 的开发者查看。PCB 原理图和具体连接器针序仍以原 `.eprj` 文件及实物为准。

原方案采用插接式模块和端子，可插接 STM32ZGT6、HWT101、TB6612、稳压模块、CAN 模块，并连接电机和舵机。原文列有省赛指示面板与集成板 3.0，以及国赛指示面板 3.1、集成板 3.1、平推转线板 3.1.1。仓库只包含固件和文档，没有将这些 PCB 设计文件纳入 Git。

## 当前机构映射

| 控制信号 | 当前机构 | 旧代码名称 |
| --- | --- | --- |
| PA3 / TIM2_CH4 | 升降电机 | 云台 |
| PA2 / TIM2_CH3 | 夹爪电机 | 物块平台 |

这是当前装配的用途定义。代码中的 PWM 测试脉宽并不能证明机械行程和运动方向，接回机构前应先核对。

## 使用和交接

上电顺序、开关默认位置、指示灯、已配置接口和上位机 USART1 通信见 [`转接板使用手册.md`](转接板使用手册.md)。对方继续用 Git 开发时按 [`Git与Codex协作手册.md`](Git与Codex协作手册.md) 接收 Bundle、构建与提交。
